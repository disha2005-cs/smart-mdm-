# AWS EC2 Deployment Guide

Complete guide to deploy the Smart Mid-Day Meal System on AWS EC2.

## Prerequisites

- AWS Account
- Basic Linux/SSH knowledge
- Domain name (optional, but recommended)

## Step 1: Launch EC2 Instance

### 1.1 Create EC2 Instance

1. Log in to AWS Console
2. Navigate to EC2 Dashboard
3. Click "Launch Instance"

### 1.2 Instance Configuration

- **Name**: `midday-meal-production`
- **AMI**: Ubuntu Server 22.04 LTS
- **Instance Type**: `t3.medium` (2 vCPU, 4GB RAM) - minimum for face recognition
  - For higher traffic: `t3.large` or `c5.large`
- **Key Pair**: Create or select existing SSH key
- **Storage**: 20GB gp3 (adjust based on expected uploads)

### 1.3 Security Group

Create security group with following inbound rules:

| Type  | Protocol | Port | Source    | Description     |
|-------|----------|------|-----------|-----------------|
| SSH   | TCP      | 22   | Your IP   | SSH access      |
| HTTP  | TCP      | 80   | 0.0.0.0/0 | Web traffic     |
| HTTPS | TCP      | 443  | 0.0.0.0/0 | Secure web      |
| Custom| TCP      | 8000 | 0.0.0.0/0 | Backend API     |

### 1.4 Launch Instance

Click "Launch Instance" and wait for it to start.

## Step 2: Connect to Instance

```bash
# Download your key pair (e.g., midday-meal-key.pem)
chmod 400 midday-meal-key.pem

# Connect via SSH
ssh -i midday-meal-key.pem ubuntu@YOUR_EC2_PUBLIC_IP
```

## Step 3: Run Deployment Script

### 3.1 Download Deployment Script

```bash
# On EC2 instance
wget https://raw.githubusercontent.com/YOUR_REPO/main/deploy/deploy-aws.sh
chmod +x deploy-aws.sh
```

### 3.2 Run Deployment

```bash
sudo ./deploy-aws.sh
```

The script will:
- Install all dependencies (Python, Node.js, PostgreSQL, Nginx)
- Setup PostgreSQL database with pgvector
- Configure services
- Setup Nginx as reverse proxy
- Configure firewall

### 3.3 Clone Your Repository

When prompted, clone your repository:

```bash
cd /opt/midday-meal
git clone YOUR_REPO_URL .
```

## Step 4: Configuration

### 4.1 Backend Configuration

Edit `/opt/midday-meal/backend/.env`:

```bash
sudo nano /opt/midday-meal/backend/.env
```

Update:
```env
DATABASE_URL=postgresql://meal_admin:YOUR_STRONG_PASSWORD@localhost:5432/midday_meal_db
JWT_SECRET_KEY=your-generated-secret-key  # Already generated by script
BACKEND_CORS_ORIGINS=http://YOUR_DOMAIN,https://YOUR_DOMAIN
```

### 4.2 Frontend Configuration

Edit `/opt/midday-meal/frontend-new/.env`:

```bash
sudo nano /opt/midday-meal/frontend-new/.env
```

Update:
```env
VITE_API_URL=http://YOUR_DOMAIN/api/v1
# Or use direct IP: http://YOUR_EC2_IP:8000/api/v1
```

### 4.3 Rebuild Frontend

```bash
cd /opt/midday-meal/frontend-new
npm run build
```

### 4.4 Restart Services

```bash
sudo systemctl restart midday-meal-backend
sudo systemctl restart nginx
```

## Step 5: SSL Certificate (Recommended)

### 5.1 Install Certbot

```bash
sudo apt install certbot python3-certbot-nginx -y
```

### 5.2 Obtain Certificate

```bash
sudo certbot --nginx -d yourdomain.com -d www.yourdomain.com
```

Follow the prompts. Certbot will automatically configure Nginx for HTTPS.

### 5.3 Auto-Renewal

Certbot installs a cron job for auto-renewal. Test it:

```bash
sudo certbot renew --dry-run
```

## Step 6: Seed Demo Data (Optional)

```bash

curl http://localhost:8000/docs

# From browser
http://YOUR_EC2_IP/          # Frontend

```

## Monitoring & Maintenance

### View Logs

```bash
# Backend logs (real-time)
sudo journalctl -u midday-meal-backend -f

# Nginx access logs
sudo tail -f /var/log/nginx/access.log

# Nginx error logs
sudo tail -f /var/log/nginx/error.log
```

### Restart Services

```bash
# Restart backend
sudo systemctl restart midday-meal-backend

# Restart Nginx
sudo systemctl restart nginx

# Restart both
sudo systemctl restart midday-meal-backend nginx
```

### Update Application

```bash
cd /opt/midday-meal

# Pull latest changes
git pull

# Update backend
cd backend
source venv/bin/activate
pip install -r requirements.txt
alembic upgrade head
sudo systemctl restart midday-meal-backend

# Update frontend
cd ../frontend-new
npm install
npm run build
sudo systemctl restart nginx
```

### Database Backup

```bash
# Backup
sudo -u postgres pg_dump midday_meal_db > backup_$(date +%Y%m%d).sql

# Restore
sudo -u postgres psql midday_meal_db < backup_20260809.sql
```

## Troubleshooting

### Backend Not Starting

```bash
# Check logs
sudo journalctl -u midday-meal-backend -n 50

# Check if port 8000 is in use
sudo netstat -tulpn | grep 8000

# Manually test
cd /opt/midday-meal/backend
source venv/bin/activate
python main.py
```

### Database Connection Issues

```bash
# Check PostgreSQL status
sudo systemctl status postgresql

# Test connection
sudo -u postgres psql -d midday_meal_db -c "SELECT version();"

# Check pgvector extension
sudo -u postgres psql -d midday_meal_db -c "SELECT * FROM pg_extension WHERE extname='vector';"
```

### Nginx Issues

```bash
# Test configuration
sudo nginx -t

# Check error logs
sudo tail -f /var/log/nginx/error.log

# Verify sites enabled
ls -la /etc/nginx/sites-enabled/
```

### High CPU Usage

Face recognition is CPU-intensive. Solutions:
1. Upgrade to larger instance (c5.large, c5.xlarge)
2. Optimize image preprocessing
3. Implement request queuing
4. Use GPU instances (p3.medium) for heavy load

### Out of Disk Space

```bash
# Check disk usage
df -h

# Clean up
sudo apt autoclean
sudo apt autoremove
docker system prune -a  # if using Docker

# Increase EBS volume in AWS console, then:
sudo growpart /dev/xvda 1
sudo resize2fs /dev/xvda1
```

## Security Best Practices

1. **Change default passwords** in `.env`
2. **Use strong JWT secret** (at least 32 characters)
3. **Enable firewall** (UFW configured by script)
4. **Setup SSL/HTTPS** (use Certbot)
5. **Regular updates**: `sudo apt update && sudo apt upgrade`
6. **Restrict SSH access** to your IP only
7. **Use IAM roles** instead of access keys when possible
8. **Enable CloudWatch** for monitoring
9. **Setup automated backups** for database
10. **Use AWS Secrets Manager** for sensitive data
