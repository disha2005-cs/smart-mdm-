STEP 2: CONFIGURE S3 BUCKET PERMISSIONS (AWS Console)
------------------------------------------------------
Go to: https://s3.console.aws.amazon.com/s3/buckets/dishadeeksha

A. Set Bucket Policy:
   1. Click "Permissions" tab
   2. Scroll to "Bucket policy"
   3. Click "Edit"
   4. Paste this policy:

{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Sid": "PublicReadGetObject",
      "Effect": "Allow",
      "Principal": "*",
      "Action": "s3:GetObject",
      "Resource": "arn:aws:s3:::dishadeeksha/students/*"
    }
  ]
}

   5. Click "Save changes"

B. Unblock Public Access:
   1. Click "Permissions" tab
   2. Scroll to "Block public access"
   3. Click "Edit"
   4. UNCHECK all 4 boxes
   5. Click "Save changes"
   6. Type "confirm"

C. Enable CORS:
   1. Click "Permissions" tab
   2. Scroll to "Cross-origin resource sharing (CORS)"
   3. Click "Edit"
   4. Paste this:

[
    {
        "AllowedHeaders": ["*"],
        "AllowedMethods": ["GET", "HEAD"],
        "AllowedOrigins": ["*"],
        "ExposeHeaders": [],
        "MaxAgeSeconds": 3000
    }
]

   5. Click "Save changes"

================================
TROUBLESHOOTING:
================================

If photos don't display:
1. Check S3 bucket policy is set
2. Check photo_url value in database (should be https://...)
3. Check browser console for CORS errors
4. Verify bucket name is "dishadeeksha" in .env

If camera doesn't work:
1. Use HTTPS or localhost (required for camera access)
2. Check browser camera permissions in settings
3. Try in Chrome/Edge (best support)
4. Check browser console for errors

If auto-mark doesn't work:
1. Verify autoMark=true in Attendance.tsx
2. Check face confidence > 65%
3. Verify face encoding exists in database
4. Check backend logs for errors
